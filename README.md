# 🐚 bash-scripts (Español)

Colección de scripts en Bash desarrollados como parte de mi aprendizaje y práctica en administración de sistemas Linux. Cada script vive en su propia carpeta con su código y documentación específica.

Repositorio vivo: se irá ampliando con nuevos scripts a medida que siga formándome y trabajando en administración de sistemas, más allá de mi etapa como estudiante de FP ASIX. Orientado a roles DevOps / SysAdmin.

## 📂 Scripts

| Script | Descripción | Nivel |
|---|---|---|
| [`media-notas`](./media-notas) | Calcula la media de un conjunto de notas introducidas por el usuario y muestra un mensaje según el resultado. | Básico (aprendizaje) |
| [`mini-ips-bash`](./mini-ips-bash) | Mini IPS que analiza logs SSH, detecta IPs con intentos de login fallidos repetidos y simula su bloqueo (estilo Fail2Ban). | Intermedio |
| [`NAS-script`](./NAS-script) | Automatización para instalar SAMBA y preparar un NAS (Importante leer el README correspondiente en su carpeta). | Intermedio |

## ▶️ Uso general

Cada carpeta incluye su propio README con instrucciones detalladas, ejemplos de ejecución y explicación del funcionamiento interno.

## ⚙️ Requisitos

- Bash 4+ (probado en Linux)
- Sin dependencias externas — cada script usa únicamente herramientas estándar de Unix (`grep`, `awk`, `sort`, `uniq`, etc.)

## 🚧 Sobre este repositorio

Estos scripts están en distintas fases de madurez: algunos son ejercicios de aprendizaje básicos (bucles, condicionales, aritmética) y otros aplican esa base a casos de uso más realistas (análisis de logs de seguridad). Cada README individual documenta honestamente las limitaciones y mejoras pendientes de cada script, en lugar de presentarlos como herramientas de producción.

# 🐚 bash-scripts (English)

A collection of Bash scripts built as part of my learning and practice in Linux system administration. Each script lives in its own folder with its own code and documentation.

Living repository: it will keep growing with new scripts as I continue learning and working in system administration, beyond my time as an ASIX vocational student. Focused on DevOps / SysAdmin roles.

## 📂 Scripts

| Script | Description | Level |
|---|---|---|
| [`media-notas`](./media-notas) | Calculates the average of a set of grades entered by the user and prints a message based on the result. | Basic (learning) |
| [`mini-ips-bash`](./mini-ips-bash) | Mini IPS that parses SSH logs, detects IPs with repeated failed login attempts, and simulates blocking them (Fail2Ban-style). | Intermediate |

## ▶️ General usage

Each folder includes its own README with detailed instructions, example runs, and an explanation of how the script works internally.

## ⚙️ Requirements

- Bash 4+ (tested on Linux)
- No external dependencies — each script relies only on standard Unix tools (`grep`, `awk`, `sort`, `uniq`, etc.)

## 🚧 About this repository

These scripts are at different maturity levels: some are basic learning exercises (loops, conditionals, integer arithmetic), while others apply that foundation to more realistic use cases (security log analysis). Each individual README honestly documents each script's limitations and pending improvements, rather than presenting them as production-ready tools.
